01 — ABOUT THE PROJECT

做了什麼？

把容易混淆的雅思閱讀判斷題，變成「找證據、認陷阱、看回饋」的小練習。

01

Evidence first

每題有經過人工編寫的正確答案與原文證據，不讓模型臨時猜答案。

02

Trap detection

辨識同義改寫、反向敘述、缺少資訊、過度推論等常見陷阱。

03

AI coaching

讓你輸入選答原因，本機 Ollama 用固定 JSON Schema 給出個人化建議。

04

Progress tracking

Python 統計答題正確率和常錯陷阱，將學習紀錄留在本機。

03 — RUN IT YOURSELF

怎麼執行？

用 VS Code 開啟程式，準備 uv 和 Ollama，就能在自己的電腦上練習。

01

安裝 uv 與 Ollama

uv 管理 Python 專案相依套件；Ollama 在本機運行語言模型。

02

開啟專案，下載模型

TERMINAL
uv sync
ollama pull qwen2.5:3b
03

啟動 AI 閱讀練習

TERMINAL
uv run main.py

要先看不需要 AI 的固定題庫：uv run main.py --demo

WHY IT MATTERS

Not Given ≠ False

FALSE：與文章中的資訊明確矛盾。

NOT GIVEN：文章沒有提供足夠資訊判斷真假。

05 — AI TRANSPARENCY

AI 使用說明

說清楚 AI 做了哪些事情、哪些部分由程式控制，以及如何驗證成果。

MODEL

Ollama × local LLM

透過 Python 呼叫本機 Ollama 模型。標準答案來自固定題庫；AI 只負責根據使用者思考過程補充學習回饋。

W6 CAPABILITY

Structured Output

使用 Pydantic JSON Schema 限定回饋格式：思考診斷、英文詞句、下次策略。每筆資料再用程式驗證格式。

VERIFICATION

Human-reviewed answers

題庫中附有標準答案、證據原句和人工撰寫解析；Python 單元測試檢查格式與原文引文。AI 解說仍需人工核對。

TOOL DISCLOSURE

AI-assisted development

本專案使用 ChatGPT 協助初版 Python 程式、README、測試及網頁開發。我使用 Ollama 的 Qwen2.5:3b 模型進行實際測試，發現 AI 曾在學生回答正確時，錯誤判斷學生的理解程度。因此，我修改程式，讓 Python 負責確認答題正確性，並在學生未提供理由時，避免 AI 擅自推測其思考過程。修正後重新測試，確認此情境下 AI 能正確回饋。AI 生成的學習建議仍需人工核對。
